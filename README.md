# 民间 Rogue

中国民俗志怪题材的浏览器端 Roguelike 构筑游戏竖切 Demo。

## 已实现内容

- Phaser 3 + TypeScript + Vite 工程结构。
- 主菜单、跑局地图、战斗、事件、寺庙商店、结算 6 个核心场景。
- 抽签、气运权重、符纸出牌、敌人意图、护身、奖励和失败结算。
- 战斗胜利后进入战利品界面，可 3 选 1 符纸或跳过。
- 符纸按效果颜色区分：攻击偏朱砂、防御偏青绿、资源偏灵蓝、特殊偏暗金。
- `localStorage` 存档，键名为 `folk-rogue-save-v1`。
- 深色纸扎戏台风 UI tokens、AI 生成素材接入、键盘和鼠标操作。
- 舞台纸幡、香灰、烟雾、节点呼吸、卡牌悬停、出牌冲击、受击震动等动效。

## 运行

```bash
pnpm install
pnpm dev
```

打开终端输出的本地地址即可试玩。

## 验证

```bash
pnpm typecheck
pnpm build
```

## 素材目录

- `public/assets/` 是游戏运行时读取的正式素材目录。
- `output/imagegen/` 只作为自动生成素材的工作目录，不在游戏代码中直接引用。
- 需要重新同步生成素材时运行：`python3 scripts/sync-imagegen-assets.py`。

## 操作

- 点击：选择节点、符纸、事件选项和商店项目。
- Enter / Space：确认或结束回合。
- Esc：返回地图或主菜单。
- 数字 1-5：战斗中选择手牌。
- 数字 1-3：战利品界面选择符纸。

## 设计约束

- 触控目标不小于 44px。
- 深色主题保证主要文字对比度。
- 不使用 emoji 作为结构图标。
- 动画保持轻量，并尊重 `prefers-reduced-motion`。
- 关键反馈动画控制在 150-300ms 左右，长循环只用于低强度氛围层。
- 视觉资源从正式 `public/assets/` 目录加载；缺图内容会继续使用程序化贴图兜底。
